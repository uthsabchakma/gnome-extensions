### Show Username (`whoami.sh`)

Run these from inside the repo folder (or use the full path to the script):

```bash
bash whoami.sh             # install (shows your login name)
bash whoami.sh --fullname  # install (shows your full name from Settings → Users)
bash whoami.sh --remove    # uninstall
```

Or uninstall from anywhere, without the script:

```bash
gnome-extensions uninstall username@local  #username is the name of the extension ~ don't change
```


After installing or uninstalling, **log out and log back in**.
